      Theme

      System follows your operating system's light/dark setting.

      Memory ceiling

      Heavy work — building charts, deep checks, loading a folder, comparing datasets, generating a PDF — runs in a separate background process. Windows is told to refuse that process any memory beyond this limit, so a dataset too large to profile stops with a message instead of consuming the machine. The app window itself is never affected.

      Time-series health

      Thresholds for the Health tab and its checks. They apply only when a timestamp column is detected; without one, none of those checks run. Changing a threshold re-judges the numbers already cached — only the documented ranges below cause anything to be read again.

      Folder watching

      Watches one folder and re-profiles as new files land, reading only what is new. A file is not read until its size has held still for the interval below and — for parquet — its footer parses, so a file still being written is never profiled half-finished.

      Folder

      Profiling cache

      Each file's statistics are stored locally the first time it is profiled, so re-opening a folder reads only files that are new or have changed since. Nothing here leaves this machine, and clearing it never loses data — only the time it takes to compute again.
